# HancyWeb

## Overview
HancyWeb is a dynamic React-based web application for course selling with Firebase as the backend. It contains user and admin dashboards with mobile-first responsive designs, managed via Firebase Authentication and Firestore.

## Features
- Firebase Email Authentication
- User Dashboard
- Admin Dashboard
- Fully Responsive (Mobile-Friendly)

## Setup Instructions
1. Clone the repository.
2. Run `npm install` to install dependencies.
3. Add Firebase config in `src/firebase.js`.
4. Run `npm start` to launch the app locally.
